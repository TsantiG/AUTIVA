# AUTIVA

**Proyectos · Estudio · Tareas · Hábitos**

AUTIVA es una aplicación Android de productividad y organización personal en desarrollo. Su propósito es ayudar a transformar metas y responsabilidades en actividades planificadas, fomentar la constancia y visualizar el progreso desde un solo lugar.

## Propuesta del producto

- Organizar proyectos y objetivos personales.
- Planificar actividades académicas y de estudio.
- Gestionar tareas y tiempos.
- Dar seguimiento a hábitos y avances.

Estas son **áreas funcionales previstas**, no una lista de funcionalidades comprobadas. La implementación de la aplicación todavía no se ha auditado en esta revisión documental.

El público propuesto incluye estudiantes, profesionales y personas que desean mejorar su organización. El idioma previsto es español.

## Estado técnico

Proyecto preparado para trabajar en Android Studio, con Kotlin, Jetpack Compose y Material 3 declarados en su configuración.

| --- | --- |
| Proyecto / módulo | `AUTIVA/` / `:app` |
| SDK mínimo | API 24 — Android 7.0 |
| SDK de compilación / objetivo | 37 / 37 |
| Android Gradle Plugin | 9.5.2 |
| Plugin Compose Kotlin | 2.2.10 |
| Compose BOM | 2026.02.01 |
| Gradle Wrapper | 9.6.0 |

Datos leídos de la configuración el 24 de noviembre de 2026. No demuestran compilación exitosa, disponibilidad del entorno ni compatibilidad probada en dispositivos. La versión requerida de Android Studio y el JDK de ejecución están pendientes de verificar.

**Compatibilidad pendiente:** el objetivo inicial era Android 6.0 (API 23), pero la configuración actual exige API 24. No se anuncia soporte para Android 6.0 hasta resolver esta diferencia y validarlo.
